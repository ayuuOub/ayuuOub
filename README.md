## 🤖 First-Year Engineering Internship — Digital Factory

My first-year Engineering Cycle internship focused on studying modern AI systems and developing a **governed multi-agent software-development workflow** using **Hermes Agent and LLM-backed specialist agents**.

The result is my [Digital Factory](https://github.com/ayuuOub/digital-factory).

The Factory coordinates 8 specialized Hermes profiles across:

- Product
- UI/UX
- Architecture
- Security
- Development
- Independent QA / Browser Validation
- Documentation
- Orchestration

The workflow uses **Hermes Kanban**, specialist responsibility boundaries, and explicit **Human-in-the-loop approval gates**.

Different LLM models and providers were used during the internship depending on the role and provider availability.

```text
Hermes Agent + LLM Models
           ↓
      Digital Factory
           ↓
Specialized AI Agents
           ↓
 Human Approval Gates
           ↓
 Task Management App
```

The [Task Management App](https://github.com/ayuuOub/task-management-app) was developed using the Digital Factory as its governed software-delivery workflow.

**Architecture distinction:** Hermes and the LLM-backed agents belong to the development process. The Task Management App itself is a standalone application and does not require Hermes or an LLM at runtime.
